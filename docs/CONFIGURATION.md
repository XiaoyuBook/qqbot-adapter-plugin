# 配置指南

首次安装步骤见 [README](../README.md#安装)。本页说明配置入口、主人授权、设置字段及私有文件管理。

## 配置入口

| 入口 | 适合的操作 | 生效方式 |
| --- | --- | --- |
| 本地交互终端 | 初始化、填写 AppID 与 AppSecret、启用或禁用连接 | 下次加载插件时生效 |
| 锅巴管理页 | 账号、连接、消息、主人、白名单与身份关联 | 保存后重新加载适配器连接 |
| 聊天命令 | 查询或修改 11 项常用开关与参数 | 保存确认后重新加载连接 |

账号启停、凭据、主人、白名单和身份关联通过锅巴或私有文件维护。聊天设置只展示允许公开到当前会话的开关、数值和连接状态。

## 私有配置

默认文件为插件目录下的 `private/account.json`，`config/default.json` 提供配置字段的默认值。私有文件中 `config` 保存设置，顶层 `appSecret` 保存凭据。

在插件目录执行以下命令生成完整私有文件，初始状态为禁用。

```sh
npm run config -- --init
```

在本机或 SSH 的交互终端填写凭据并启用连接。

```sh
npm run config -- --enable
```

配置工具会询问 AppID 和隐藏输入的 AppSecret。空密钥保留已有值，切换 AppID 必须重新填写密钥，取消输入会放弃保存。工具仅接受 `--init`、`--enable`、`--disable`，凭据通过终端提示输入，保存后在下次加载插件时生效。

单独调整凭据可执行 `npm run config`。禁用可在锅巴关闭「启用连接」，或将私有文件的 `config.enabled` 改为 `false` 后重新加载插件。`npm run config -- --disable` 也会经过相同的凭据交互。

### 配置目录与权限

生产环境可为喵崽进程设置 `QQBOT_ADAPTER_PRIVATE_DIR`，例如 `/var/lib/qqbot-adapter-plugin`。配置工具和喵崽应使用同一路径、同一运行用户，Docker 环境应持久挂载该目录。

POSIX 系统的私有目录和文件使用 `0700`、`0600` 权限，配置存储会拒绝符号链接、硬链接和其他用户所有的文件。Windows 请使用受限用户目录和 NTFS ACL。插件内仅允许使用 `private/` 作为私有配置目录。

AppSecret 在私有 JSON 中以磁盘明文保存，应限制文件访问并妥善保管备份。同用户进程和系统管理员仍可访问该文件。密钥应留在受控终端、管理页与私有存储中，公开反馈仅提供脱敏错误信息。

## 锅巴配置

加载插件后，在锅巴的插件配置中打开「QQ 官方机器人适配器」。页面提供以下设置。

| 分类 | 主要字段 |
| --- | --- |
| 账号与连接 | 启用连接、AppID、写入 AppSecret、已配置密钥、沙箱 API |
| 事件接收 | 群消息总开关、C2C、免 @、入群申请和成员变动 |
| 消息与群管 | 群图片提及、主动发送、群管角色兼容 |
| 权限与身份 | 两种场景的主人 OpenID、访问白名单、旧 QQ 数据关联 |
| 数值参数 | 回复窗口、回复次数、请求超时、重连间隔及媒体大小 |

AppSecret 是只写字段，管理页读取配置时返回空字符串和 `secretConfigured` 状态。空输入保留已有密钥，切换 AppID 时重新填写。页面保存后重新加载适配器连接，若提示运行时加载失败，应检查状态并安排重新加载宿主。

使用可信终端，通过 HTTPS 或 SSH 隧道访问管理页。密码框遮罩只影响显示，密钥仍会经过浏览器和管理请求。

## 主人与访问范围

主人配置和白名单分别控制管理权限及允许接收的消息范围，每行填写一个**原始 OpenID**。

| 字段 | 填写内容 | 空列表含义 |
| --- | --- | --- |
| `masterGroupOpenids` | 群消息发送者的 `member_openid` | 群聊中无人获主人授权 |
| `masterC2COpenids` | 私聊发送者的 `user_openid` | C2C 中无人获主人授权 |
| `allowedGroupOpenids` | 允许接收消息的 `group_openid` | 本地允许该场景全部群 |
| `allowedC2COpenids` | 允许接收消息的 `user_openid` | 本地允许该场景全部私聊用户 |

可信管理员应通过受控测试身份核实 OpenID。开发调试时，当前消息发送者与群的原始标识分别位于 `e.qqbot.userOpenid`、`e.qqbot.groupOpenid`，AppID 和场景位于 `e.qqbot.appId`、`e.qqbot.scope`。仅在受控本地环境核对这些字段，并避免把身份信息写进公开日志或截图。

QQBot 会话中的 `e.isMaster` 由当前 AppID 和场景内的主人列表决定。群聊和 C2C 分别授权，群主人授权适用于该 AppID 下匹配的 `member_openid`，可结合群白名单限制范围。QQ群角色、宿主 `masterQQ` 和旧数据关联各自独立管理。

通过其他已接入协议的聊天入口管理本插件时，命令会校验宿主提供的 `e.isMaster`。设置目标始终为当前 QQBot 适配器账号。

### 旧数据关联

`userIdMappings` 是 JSON 对象，将完整平台主体关联到已核实的既有 QQ 数据归属字符串。主体形式如下。

```text
qqbot:<AppID>:group-user:<member_openid>
qqbot:<AppID>:c2c-user:<user_openid>
```

关联用于业务数据读取，发送时仍使用对应平台 OpenID，主人权限继续由上述主人列表决定。群聊与 C2C 分别关联，跨 AppID 分开管理。关联和离线迁移的范围见 [身份与数据关联](IDENTITY.md)。

## 聊天设置对应字段

使用 `#QQBot设置<项目>` 查询单项，`#QQBot设置<项目><值>` 修改，`#QQBot设置<项目>默认` 恢复默认。完整命令表见 [README](../README.md#修改设置)。

| 聊天项目 | 配置字段 | 作用 |
| --- | --- | --- |
| 免艾特 | `receiveGroupMessages` | 接收平台推送的非 @ 群消息，还需群内授权与宿主 `onlyReplyAt=0` |
| 图片艾特 | `mentionBeforeImage` | 群图片默认同条消息上方 @、下方图片，私聊使用普通图片 |
| 群通知 | `receiveGroupNotices` | 接收入群申请和成员变动事件 |
| 群管兼容 | `groupManagement` | 查询并缓存机器人在群内的真实角色 |
| 主动消息 | `allowProactive` | 允许向已观察且通过本地范围检查的联系人主动发送 |
| 群回复窗口 | `replyWindowSeconds` | 群事件被动回复的有效秒数 |
| 私聊回复窗口 | `c2cReplyWindowSeconds` | C2C 事件被动回复的有效秒数 |
| 回复次数 | `maxReplies` | 每条触发的本地回复上限，C2C 同时受最多 4 次限制 |
| 请求超时 | `requestTimeoutMs` | 聊天按秒填写，文件和锅巴按毫秒保存 |
| 图片上限 | `maxImageBytes` | 聊天按 MiB 填写，文件和锅巴按字节保存 |
| 媒体上限 | `maxMediaBytes` | 本地语音、视频和文件的大小上限，文件和锅巴按字节保存 |

`receiveGroup` 是群消息总开关，`receiveC2C` 控制私聊接收，两者在锅巴或私有文件中设置。QQ 资料页的主动推送授权与群消息接收授权分别生效。Markdown 图片素材、主动发送和群管仍受各自的平台及群内权限约束。

聊天设置对当前账号全部会话生效。修改后短暂离线属于连接重载过程，连接恢复后可再次查询设置。提交相同值时保留当前连接。

## 连接与回复参数

默认群聊被动回复窗口为 240 秒，每条触发最多 5 次。C2C 默认 3600 秒，最多 4 次，并受 `maxReplies` 配置限制。窗口按原事件时间计算。

重连间隔由 `reconnectMinMs` 和 `reconnectMaxMs` 控制，默认 1000 和 60000 毫秒。适配器通过心跳、连接恢复及退避机制处理断线，遇到不可重试错误时进入受限状态。连接状态可在设置图查看。

同一进程内的去重覆盖连接恢复与同 AppID 配置重载，默认保留两小时、最多 20000 个事件键。满载时拒绝新事件，业务插件仍需处理进程重启后的重复事件。
